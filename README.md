# ePortfolio — Thibault Larroque

ePortfolio réalisé dans le cadre de la **SAé14** du BUT Réseaux et Télécommunications (IUT Blagnac).
Il présente mon parcours, mes motivations et les éléments livrables du projet.

🔗 **Site en ligne :** https://leviathan63.github.io/eportfolio/

## Pages

| Page | Contenu |
| --- | --- |
| `index.html` | Accueil : pourquoi ce portfolio, qui suis-je |
| `eportfolio.html` | Définition, objectifs et contexte du ePortfolio |
| `about.html` | Présentation personnelle, hobbies, citation favorite |
| `parcours.html` | Bac STI2D, projet de spécialité, choix du BUT R&T |
| `livrables.html` | Plan du site, charte graphique, responsive, arborescence, Gantt |
| `contact.html` | Email, téléphone et réseaux |
| `mentions_legales.html` | Mentions légales |

## Arborescence

```
eportfolio/
├── *.html        pages du site
├── css/
│   └── style.css feuille de style
├── images/       images et badges
└── videos/       vidéos (hobbies, projet RFID)
```

## Technologies

- HTML5 sémantique (`header`, `nav`, `main`, `section`, `aside`, `footer`)
- CSS3 + [Bootstrap 5.3](https://getbootstrap.com/) pour le responsive
- Police [Poppins](https://fonts.google.com/specimen/Poppins) et icônes [Font Awesome](https://fontawesome.com/)

Toutes les pages sont valides selon le [validateur HTML du W3C](https://validator.w3.org/nu/),
et la feuille de style selon le [validateur CSS du W3C](https://jigsaw.w3.org/css-validator/).

## Lancer le site en local

Aucune installation nécessaire : ouvrir `index.html` dans un navigateur.

## Branches

- `main` : version statique en HTML (celle-ci)
- `dev` : version PHP avec templates (en-tête, menu et pied de page partagés)
