Architecture et charte graphique

Le site utilise une structure HTML5 sémantique avec les balises <header>, <nav>, <main>, <section> et <footer>. La charte graphique repose sur :

  • Couleurs dominantes : rouge, gris foncé et blanc
  • Typographie principale : Poppins, sans-serif
  • Effets d’ombre, coins arrondis et transitions au survol
  • Design responsive via media queries pour les écrans < 768px

Responsive Web Design

Le site a été testé sur différents outils en ligne pour vérifier sa compatibilité mobile et tablette :

  • Responsinator
  • Website Planet

  • GTMetrix pour la performance
